# Farm2Home 🌾

Farm2Home is a full-stack agriculture marketplace that connects farmers directly with buyers, eliminating middlemen and enabling transparent, efficient trade.

## Features
- 👨‍🌾 Farmer Dashboard
  - Add and manage products
  - View market prices
  - Sales analytics
  - Track buyer purchases

- 🛒 Buyer Dashboard
  - Browse products
  - Shopping cart
  - Favourite products
  - PDF bill generation

- 📊 Analytics
  - Sales insights
  - Interactive charts
  - Product performance

## Tech Stack
- React
- Node.js
- Express.js
- MongoDB
- Bootstrap

## Goal
Empower farmers by providing a digital marketplace that increases market access, transparency, and profitability.
